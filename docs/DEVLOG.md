# 开发日志

## 2026-11-15 — M0/M1 骨架与水体

### 已落地
- Vite + TypeScript + Three.js 0.187 脚手架，严格模式 TS（`tsc --noEmit` 通过）
- 程序化场景：沙床（噪声起伏 + 石子 + 层理断面）、岩石簇、沉木、46 株实例化水草
- 程序化焦散：迭代 sin 折叠算法渲染到 512² RT，每帧更新，按世界坐标投影到所有水下表面
- 水下介质 pass：世界坐标重建 + Beer-Lambert 分通道吸收 + 内散射
- 玻璃：4 面折射面板叠加在介质结果之上（sceneRT 偏移采样 + 菲涅尔 + 边缘高光）+ 硅胶边框与柜体
- 水面：双面，顶点波浪 + CPU 波动方程涟漪场（DataTexture 回传），菲涅尔 + 太阳高光 + 玻璃边缘弯月面亮线
- 后处理：景深（线性化深度）、God rays（径向模糊）、5 级 mip 泛光、ACES、色差、颗粒、暗角
- 7 条鱼：4 个品种的程序化身体网格、顶点着色器行波摆尾、3 层鱼材质（渐变底色 + 鳞片格 + 菲涅尔虹彩 + wrap diffuse SSS）、半透明鱼鳍、反光眼睛

### 踩过的坑（值得记住）
1. **MSAA + depthTexture 不安全**：`samples > 0` 时读回的深度纹理不可靠，导致整屏被判定为远景水体，画面全黑。已改为不使用 MSAA，靠 `pixelRatio` 超采样。
2. **half-float 链路上的 NaN 会永久污染画面**：一个 NaN 进入泛光求和后整张图变黑。所有后处理采样点统一走 `sane()` 夹取。
3. **背景像素（深镀 = 1.0）必须早退**：否则雾会铺满视口形成"白墙"。
4. **玻璃覆盖层不能画在清空的目标上**：必须先把介质结果 copy 过去再叠玻璃。
5. **雾深度要用线性化深度**：直接拿深度缓冲值做 DOF 半径会导致全屏糊成一片。

### 验证方式
`tools/shot.mjs`（puppeteer-core + 本机 Chrome）无头截图，同时收集 console 报错与渲染统计。
调试开关：`?debug=plain|base|nodof|nofx|u1|u2`。

### 当前状态
无 console 报错，1080p 高画质（软件渲染下）稳定出图。

## 2026-11-15 — M4/M5 打磨、性能档位与交付

### 修复的实质缺陷（代码审查发现）
1. **受惊逃跑方向是错的**：`School.interest` 从未被更新，`scare()` 只加了速度，鱼随后仍朝同一个陈旧坐标逃跑。改为在 `scare()` 里记录惊吓源。
2. **画质切换只改了分辨率**：后处理开关、泛光 mip 链、粒子数量都没跟着变。新增 `Post.setQuality()`、`Bubbles/Dust.setCount()`，主循环里的 `applyQuality` 三者一起切。
3. **每帧分配对象**：转向与光源投影每帧 `new Matrix4()/Quaternion()/Vector3()`，在 60fps 下是稳定的 GC 压力。改成模块级临时对象复用。
4. **鱼群重叠**：分离半径 0.95 小于鱼身长度，鱼会互相穿模。提高到 1.9，并把分离权重从 2.6 提到 3.2。
5. **鱼鳍过曝**：`(0.35 + 1.9 * casc)` 在焦散峰值处把鳍推到纯白，看起来像纸片。收敛到 `(0.16 + 0.80 * casc)` 并对颜色做了上限夹取。
6. **页面切回前台时物理跳变**：`visibilitychange` 里补一次 `clock.getDelta()` 丢弃停顿时长。

### 体验补全
- 闲置 6 秒后相机开始缓慢环绕，画面不会静止得像截图
- 品种差异化：彗星鱼尾鳍更长（`tailSpan` 按体型分支），游速更快
- 体色饱和度上调、整体曝光下调（0.62 → 0.50），画面不再发灰发白

## 2026-11-15 — 鱼尾布料模拟与游动节奏重做

### 发现的致命 bug：摆尾行波一直是静止的
`behavior.ts` 里 `f.phase = t * f.swimFreq`，而着色器里是 `sin(... - uSwimPhase)`，
`uSwimFreq` 又是 `f.swimFreq`。两者相减正好抵消成常数 —— 每条鱼的尾波只随自身相位滑移，
根本没有在摆动。这就是"动作僵硬不自然"的根源之一。
改为在 CPU 上积分 `f.phase += f.swimFreq * dt`，并从 `swimOffset()` 里删掉 `uTime * uSwimFreq` 项。

### 鱼尾改为 Verlet 布料（`src/cloth.ts`）
- 布料在鱼的**局部空间**模拟：根行钉在身体的摆尾波上，其余顶点靠约束继承惯性
- 约束：结构 / 剪切 / 弯曲三级，Jacobian 松弛迭代 3 次
- 迭代过程中踩了两个坑：
  1. **把水流当位置偏移** → 每一帧都在加速度，尾巴被拉成直棒并飞出水面。改为弹簧目标式耦合。
  2. 最终采用**弹簧目标式 Verlet**：把"摆尾波 + 水阻滞后 + 鳍自身颤动"合成为运动目标，
     用阻尼弹簧去追。薄片在真实帧率下稳定，同时保留可见的滞后与飘动
- 远场细节：沿鳍展方向加行波相位 `- r * 4.2`，膜面是涟漪而不是整体平移
- 尾鳍不再叠加着色器摆尾（顶点已在 CPU 定稿），用独立材质

### 节奏放慢
| 参数 | 旧值 | 新值 |
|---|---|---|
| 摆尾角频率 | 8.0 + sp*2.2 | 3.2 + sp*1.0 |
| 转向跟随 | `exp(-dt*6)` | `exp(-dt*3.2)` |
| 巡航速度 | 0.85–1.4 | 0.62–1.0 |
| 速度上限 | 2.4 | 1.7 |
| 加速平滑 | `exp(-dt*2.4)` | `exp(-dt*1.15)` |
